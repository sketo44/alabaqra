# العباقرة — النسخة الثانية

مشروع React 19 / Vite 7 عربي RTL، أعيد تصميمه بالشعار والصور والمعلومات المنشورة في موقع الشركة بناءً على طلب المستخدم. المعاينة غير رسمية وغير منشورة للعامة.

## التشغيل

يتطلب Node.js 20.19+ أو 22.12+.

```
npm ci
npm run dev
```

للإنتاج:

```
npm run build
npm run preview
```

الصفحات: / و/projects و/company و/gallery و/news و/page?id=…

الصور والشعارات في public/assets. المحتوى ومصادره في public/site-data.json. الخطوط من النظام. عبارات العقود والأعداد والتواريخ المنقولة من المصدر تاريخية، ولا تثبت الوضع الحالي. الحقوق لأصحاب المحتوى. المعاينة تمنع الفهرسة عمدًا. عند النشر يلزم ضبط إعادة توجيه مسارات SPA إلى index.html.

## نظام التصميم
المعاينة /design-system، والدليل DESIGN.md، ومكتبة الخطوط docs/ARABIC-FONTS.md.
مصدر المتغيرات src/design-system/tokens.json. شغّل npm run tokens بعد التعديل وnpm run check:design لفحص الاتساق. التوليد تلقائي قبل dev/build. الخطوط في صفحة النظام مقترح مراجعة ولا تتعمم تلقائيًا على الموقع. جميع الخطوط محلية مع تراخيصها في public/fonts. لم يُضف shadcn إلى تطبيق Vite؛ المهارة العامة متاحة للمشاريع التي تستخدمه.


## GitHub Pages

نسخة معاينة غير رسمية، لا تمثل الموقع الرسمي للشركة. حقوق الشعارات والصور لأصحابها؛ مراجع الصور والشعارات والخطوط في docs/. لا يحتوي المشروع على خدمة إرسال لطلبات التوظيف.

المستودع alabaqra. GitHub Actions يبني نسخة المسار /alabaqra/ وينشرها على Pages عند تحديث main. صفحات المسارات المباشرة تستخدم 404.html لاستعادة واجهة React.
